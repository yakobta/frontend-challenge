HTML FUNDAMENTALS

Every link needs a path.

Learn how to connect pages and external resources using the right URL or file path.

Explore the guide

Three ways to locate resources

01 / LOCAL FILES

Absolute filesystem path

Specifies the full location of a file on a particular computer.

/Users/mac/Documents/about.html

Useful when identifying a local file, but generally unsuitable for portable website links.

02 / EXTERNAL RESOURCE

Absolute URL

Provides the complete web address of an external resource.

https://www.freecodecamp.org/
Visit freeCodeCamp ↗
03 / INTERNAL RESOURCE

Relative path

Locates a file relative to the current document.

pages/about.html
Open the About page →

DIRECTORY EXAMPLE

Understand the relationship

path-explorer/
├── index.html
├── style.css
└── pages/
    ├── about.html
    └── contact.html

From index.html, use pages/about.html to open the About page.

From pages/about.html, use ../index.html to return home.

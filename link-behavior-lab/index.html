Four important values

01

Current context

target="_self"

Opens the destination in the current tab or context.

02

New context

target="_blank"

Usually opens the destination in a new browser tab.

03

Parent context

target="_parent"

Opens in the parent context. Outside frames, it behaves like the current context.

Open example.com
04

Top-level context

target="_top"

Targets the full browser tab, escaping embedded frames when applicable.

QUICK REFERENCE

Choose the right target

_self

Normal navigation within the current context.

_blank

Open a link in a new context, commonly a new tab.

_parent

Use the parent context, especially when working with iframes.

_top

Use the top-level browser context.

_unfencedTop

An experimental value for specific fenced-frame use cases.

Developer tip

Use descriptive link text so visitors know what they are opening. When opening external links in a new tab, consider the user's expectations and add appropriate rel attributes.

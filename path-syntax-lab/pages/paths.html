PATH REFERENCE

Three rules to remember.

Each relative path starts from the directory of the document using it.

← Back to home

Slash /

css/style.css

Enter the css directory and locate style.css.

Single dot ./

./paths.html

From this page, this refers to the same paths directory.

Double dot ../

../index.html

Move up from pages to the project root and open index.html.

Challenge: find the stylesheet

You are currently in pages/paths.html. The stylesheet is in css/style.css at the project root.

Your correct path is:

../css/style.css

First move up one directory. Then enter css and locate style.css.

Understanding link states

CSS pseudo-classes let you style links according to their current interaction state.

1. Unvisited link

The :link pseudo-class selects an unvisited link.

a:link {
  color: #2563eb;
}

2. Visited link

The :visited pseudo-class indicates a previously visited destination.

a:visited {
  color: #8b5cf6;
}

3. Hover

The :hover pseudo-class applies when a pointer is over a link.

a:hover {
  color: #dc2626;
}

4. Focus

The :focus-visible pseudo-class helps show keyboard focus.

a:focus-visible {
  outline: 3px solid #16a34a;
  outline-offset: 4px;
}

5. Active

The :active pseudo-class applies while a link is being activated.

a:active {
  color: #111827;
}

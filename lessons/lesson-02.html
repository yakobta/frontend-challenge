LESSON 02 · HTML

Understanding paths and URLs

I learned how to point links to web addresses and files in different locations.

What I learned

Absolute URL

A complete web address that includes the scheme and domain.

<a href="https://www.freecodecamp.org/">
  Visit freeCodeCamp
</a>

Relative path

A location described in relation to the current document's URL. It is useful for linking to pages and assets within the same website.

<a href="pages/about.html">About</a>

Absolute filesystem path

A path such as /Users/mac/Desktop/example.html identifies a file on a particular computer. It is not normally a suitable website link because it won't work for other visitors.

Why it matters

Incorrect paths create broken links and missing images or stylesheets. Relative paths help keep a website portable when its files are deployed to a server.

For normal HTML documents, relative URLs resolve from the document's URL, unless the page defines a different base URL.

LESSON 04 · CSS

Understanding CSS link states

I learned that CSS can change a link's appearance according to the user's interaction.

What I learned

These states are selected with CSS pseudo-classes. A pseudo-class starts with a colon.

  • :link: an unvisited link.
  • :visited: a link to a destination the browser records as visited.
  • :hover: the pointer is over the link.
  • :focus: the link has focus.
  • :active: the link is being activated, such as while a mouse button is held down.
a:link { color: blue; }
a:visited { color: purple; }
a:hover { color: red; }
a:focus-visible {
  outline: 3px solid green;
}
a:active { color: black; }

Why it matters

Link states communicate interaction, help people recognize visited destinations, and support keyboard navigation. Focus indicators should be visible and must not be removed without an accessible replacement.

The common order is LVHFA: link, visited, hover, focus, active. This helps avoid later rules overriding earlier ones when selectors have equal specificity.

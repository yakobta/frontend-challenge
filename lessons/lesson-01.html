LESSON 01 · HTML

Understanding HTML link targets

I learned how the target attribute controls where a linked page opens.

What I learned

An HTML link uses the <a> element. Its href attribute specifies the destination, while target tells the browser where to open that destination.

<a href="https://example.com" target="_blank">
  Visit Example
</a>
  • _self: open in the current browsing context. This is the default.
  • _blank: open in a new tab or window, depending on the browser.
  • _parent: open in the parent browsing context, when one exists.
  • _top: open in the top-level browsing context.
  • _unfencedTop: a specialized target for navigating out of a fenced frame, where supported.

Why it matters

Choosing a target affects how people move between pages. Opening external resources in a new tab can help people keep their place, but it should be used thoughtfully.

For links using target="_blank", adding rel="noopener" is a useful explicit security practice.

<a href="https://example.com"
   target="_blank"
   rel="noopener">
  Open external site
</a>

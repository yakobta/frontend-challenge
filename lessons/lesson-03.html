LESSON 03 · HTML

Learning path syntax

I learned to use /, ./, and ../ to describe where files are located.

What I learned

The forward slash: /

Separates directory names in web paths.

pages/about.html
css/style.css

Single dot: ./

Refers to the current directory. It is often optional in a relative URL.

./about.html
about.html

Double dot: ../

Moves up one directory level.

../css/style.css

If a page is located inside a pages folder, ../css/style.css goes up to the parent folder and then enters css.

Example folder structure

my-app/
├── index.html
├── css/
│   └── style.css
└── pages/
    └── about.html

From pages/about.html, the stylesheet path is ../css/style.css, while the homepage path is ../index.html.
